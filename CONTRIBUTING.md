# Contributing

1. Read `docs/dev.md` for setup and `docs/roadmap-v4.md` + `docs/roadmap-decisions.md` for the plan.
2. Keep each PR to one roadmap step. Run the frontend and Rust checks before pushing.
3. Never break the invariants in section 00 of the roadmap; add a test when you touch them.
4. Do not commit real API keys, private stories or personal data. Test fixtures must be fictional.
